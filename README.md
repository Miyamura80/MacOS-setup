## ⌨️ Useful `iterm2` shortcuts

- `CMD + D`: Split screen vertically
- `CMD + ;`: Autocomplete dropdown
- `CMD + SHIFT + C`: Copy output from last terminal execution

Other useful features:
- `imgls` - see images in directory
